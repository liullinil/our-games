# Состояние работы: «Игрострой», 21 сентября 2026

Файл живёт для того, чтобы следующий агент продолжил с того же места. Всё,
что ниже, проверено на сегодняшнем дереве; закоммичено и запушено.

```bash
npm run build && node scripts/validate-content.mjs && node scripts/check-links.mjs
```

Сейчас: **177 игр, 111 студий, 25 движков, 24 платформы, 30 серий.**
Статьи — у всех 177, скриншоты у 165, видео у 176.

## 1. Что сделано после прошлой передачи

### Карта связей переделана

Владелец забраковал прежнюю задумку: «Карта никуда не годится, бессмысленная
по задумке… получается длинная узкая полоса, которой неудобно пользоваться».
Выбрана и сделана лента времени плиткой: колонка — год, карточки внутри
колонки лежат сверху вниз, строк-студий нет вовсе. Лента свёрнута по эпохам,
иначе сетка 37 на 11 вытянулась бы на шесть тысяч пикселей вширь.

Связи рисуются только при наведении: выбранный вид родства дугой в акцентном
цвете, прочие связи той же игры пунктиром, остальная карта гаснет. Для
преемственности и общей серии обходится вся цепочка целиком.

Перетаскивание, масштаб, полоса студий и шкала лет не нужны — карта листается
как страница, клиентский скрипт похудел вдвое.

### Родство студий заполнено

Пятнадцать связей, все из текста наших же статей: 4A Games, Vostok Games и
Deep Shadows от GSC, Owlcat и Allods Team от Nival, Ino-Co от X-bow, BlackMark
от Seaward, Katauri от Elemental Games, «Сатурн-плюс» за S.K.I.F., Lesta от
Wargaming, Fulqrum и 1C Game Studios внутри «1С», IT Territory в Mail.Ru
Games, Warm Lamp внутри Alawar, Melesta у Wargaming.

Подписи у вида `parent` переписаны: «дочерняя студия» читалось одинаково с
обеих сторон, теперь «входит в» и «в состав входят».

### Игры 2025 года

В базе не было ни одной игры новее 2024-го. Добавлены Broken Arrow, PIONER,
Hail to the Rainbow и No, I'm not a Human, а с ними пять студий: GFA Games,
Steel Balalaika, Trioskaz и издатели Slitherine и Critical Reflex.

У студий `city` и `founded` стали необязательными: у Steel Balalaika город
нигде не назван, у Trioskaz — ни город, ни год. Вписывать наугад нельзя,
бросать заметные релизы из-за одного поля — тоже.

### Геймплейные ролики

Было у 34 игр из 173, стало у 131. Отдельный проход `--gameplay` меняет
приоритеты местами: запрос идёт сразу за геймплеем и он же выигрывает по
рейтингу.

Главное — раздел «Игровой процесс» **не находился никогда**: в правиле стояло
`игров\w* процесс`, а `\w` в JavaScript кириллицу не берёт. Сколько бы роликов
ни нашли, в текст они не попадали.

### Мобильные игры

Fishdom, Homescapes и Township закрыты снимками из App Store: Apple отдаёт
карточку приложения открытым JSON без ключа. Скрипт `appstore:fetch` устроен
как `steam:fetch` — ищет по названию сам и принимает только строгое совпадение.

### Починенные ошибки в данных

- **TheEngine** числился за Elemental Games и выводился из «Космических
  рейнджеров 2». На деле его написала SkyFallen для «Магии крови», а Katauri
  взяла по лицензии. Исправлено, у «рейнджеров» движок убран как
  неподтверждённый.
- **Ссылки в статьях о платформах не были ссылками**: все одиннадцать статей
  писались с потерянными квадратными скобками, 53 штуки.
- **Валидатор пропускал ссылки на несуществующие записи** — теперь сверяет
  platforms, engines, publishers, predecessors, developer и series с диском.
- **Пустая галерея** `gallery:` без пунктов читалась YAML как null и роняла
  сборку; проверка добавлена.

## 2. Что осталось

### 2.1. Дополнить статьи новыми полями — главное

Готово **27 из 177**. Задание — `docs/enrich-brief.md`, образец —
`src/content/games/35mm/index.md`. Запускать пачками по пять игр на агента.

Список оставшихся:

```bash
node -e "const fs=require('fs'),p=require('path');const d='src/content/games';
for(const id of fs.readdirSync(d).sort())
 if(!/^availability:/m.test(fs.readFileSync(p.join(d,id,'index.md'),'utf8')))console.log(id)"
```

Агенты часто находят настоящие ошибки в данных — читайте их отчёты целиком,
а не только список файлов. Так нашлись и чужой движок у Elemental Games, и
нехватка платформ у «Блицкрига» и «Чёрной книги».

### 2.2. Двенадцать игр без единого кадра

```
black-raven diversant gorodki klad legend-dragons men-of-war-2
mir-tankov nlo-vrag-neizvesten perehvatchik safari shtyrlitz snaiper
```

Проверено и не помогло: Steam, Википедия, Викисклад. Что осталось:

- советские автоматы («Городки», «Перехватчик», «Сафари», «Снайпер») —
  свободных снимков нет нигде, кроме «Морского боя» и «Магистрали», которые
  уже разобраны;
- спектрумовские («Чёрный ворон», «НЛО») и компьютерные восьмидесятых
  («Клад», «Диверсант») — возможный источник emuverse и zxpress, но кадры там
  без указания прав;
- `mir-tankov` и `legend-dragons` — официальные сайты, кадры под «Промо»;
- `men-of-war-2` и `shtyrlitz` — старые издания без витрин.

### 2.3. «Диверсант» без видео

Единственная игра совсем без роликов. Поиск приносит сериал «Диверсант» и
мод для S.T.A.L.K.E.R. с тем же названием; настоящего ролика про игру для
Радио-86РК найти не удалось.

### 2.4. Студии-издатели, которых не хватает

Агенты просились сослаться и не смогли: **HypeTrain Digital** («Чёрная
книга»), **Atent Games** (консольные ATOM RPG), **Konami** и **Iceberg
Interactive** (Blades of Time), **Kalypso Media**, **KranX Productions**,
**Virtual Programming**, **VK Play**, **4Divinity**.

### 2.5. Раздача файлов

Схема и страница это умеют: файл кладётся в `public/downloads/<id>/`,
валидатор проверяет и наличие файла, и что лицензия позволяет. **Ни одного
файла не залито**, и агентам заполнять `files` запрещено — решение по каждому
за человеком.

Единственный найденный кандидат — «Блицкриг»: 1 мая 2025 года Nival выложила
исходники на GitHub, но лицензия запрещает коммерческое использование, так
что свободной её считать нельзя.

## 3. Как проверять

```bash
node scripts/validate-content.mjs   # схема, годы, ссылки на записи, рецензии
node scripts/check-links.mjs        # относительные ссылки внутри статей
npm run steam:check                 # кадры из Steam принадлежат своим играм
npm run wiki:check                  # то же для Википедии (нужна сеть)
npm run contrast:check              # контраст во всех темах
npm run coverage                    # где пробелы
npx astro check                     # типы
npm run build                       # связи между записями
```

Предпросмотр как на Pages: `npm run serve:pages`, затем
`http://localhost:4330/our-games/`. Карта — `/our-games/graph/`, образцовая
статья — `/our-games/games/35mm/`.
