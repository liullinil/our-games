Изометрический движок московской [Nival](../../studios/nival/), сделанный для реал-тайм стратегии «Блицкриг» (2003) о Второй мировой войне: сотни единиц техники на поле боя одновременно и генератор случайных миссий для одиночной кампании.

## Технология

Движок рисует классическую изометрическую картинку с большим числом детализированных моделей танков, самолётов и пехоты на экране одновременно, а миссии одиночной кампании отчасти собираются генератором заново при каждом прохождении.

## Игры

На движке вышли «[Блицкриг](../../games/blitzkrieg/)» (2003) с обоими дополнениями и «Блицкриг II». Саму технологию Nival активно отдавала на аутсорс небольшим студиям для самостоятельных, часто не связанных с «Блицкригом» по сюжету игр: «Сталинград» (DTF Games, 2004), «Kursk» (ACTive Gaming, 2005) и финская «Talvisota: Icy Hell» (Blitzfront Game Studio, 2007) — судя по всему, последняя игра на движке.

## Судьба

Сама Nival после «Блицкрига 2» перешла на другие технологии для новых жанров. К движку студия вернулась спустя двадцать лет: в честь юбилея «Блицкрига 2» основатель Nival Сергей Орловский опубликовал на GitHub его исходный код — движок, редактор карт и скрипты — под некоммерческой лицензией.
