Д. Г. Баранов — программист из Николаева, в 1987 году написавший для домашнего компьютера [БК-0010](../../platforms/bk-0010/) свою версию игры «[Клад](../../games/klad/)» — переработки японской головоломки Rise Out. Это одна из самых ранних документированных версий игры для советских восьмиразрядных компьютеров.

## История

О самом Баранове источники сохранили только имя с инициалами, город и год работы — других биографических сведений не задокументировано. Как и множество советских программистов-одиночек середины восьмидесятых, он не состоял ни в студии, ни в кооперативе: просто написал игру для собственного компьютера и распространил её так, как тогда распространялось всё любительское программное обеспечение, — переписыванием с кассеты на кассету.

## Игры

Версия «[Клада](../../games/klad/)» для БК-0010 (1987) — единственная известная по имени работа Баранова. В том же 1987 году, независимо друг от друга, свои версии той же игры написали программисты для «Радио-86РК» и других советских платформ.
