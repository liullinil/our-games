# Игрострой

Энциклопедия компьютерных игр СССР, России и соседних стран: Украины, Беларуси,
Казахстана, Армении, Грузии, Прибалтики. От «Тетриса» на «Электронике-60» и
карманной «Ну, погоди!» до Atomic Heart, INDIKA и S.T.A.L.K.E.R. 2.

Сайт: **https://liullinil.github.io/our-games/**

## Что здесь есть

- **Карта связей** — главная страница энциклопедии. По горизонтали годы,
  по вертикали студии; полоса с их названиями держится слева при прокрутке.
  Вид родства выбирается одной кнопкой из четырёх (продолжение, одна серия,
  общий движок, общий издатель), и включён всегда ровно один: вместе они дают
  сотни линий, и карта перестаёт читаться. Наведение подсвечивает всю цепочку,
  нажатие открывает карточку с обложкой и тем, что про игру есть.
- **Шесть измерений вместо одного.** Игра связана со студией-разработчиком,
  издателем, серией, движком, платформами и эпохой; у каждого измерения свой
  раздел, и из любого можно пойти дальше.
- **Платформы как отдельные статьи** — от «Электроники-60», БК-0010 и клонов
  ZX Spectrum до Dendy, PlayStation 5 и смартфонов: что это было технически и
  во что на этом играли здесь.
- **Оформление по эпохам** — пять тем: люминофор советского терминала, серый
  пластик Dendy и окна Windows 95, глянец нулевых, плоский дизайн десятых,
  широкий гротеск двадцатых. У каждой есть светлый и тёмный вариант,
  переключатель в шапке. На странице эпохи — мозаика узнаваемых образов
  времени: приставки, компьютеры и телефоны, на которых в это играли.
- **Скриншоты и обложки** из Steam и Википедии, фотографии техники — с
  Викисклада на свободных лицензиях.
- **Видео с YouTube и Rutube** — обзоры, ретроспективы и геймплей;
  подгружаются по нажатию, а не при открытии страницы.
- **Отметки о прочитанном** — статья помечается сама, когда дочитана до конца;
  перенос между устройствами через страницу прогресса.

## Запуск

```bash
npm install
npm run fonts:sync   # разово: копирует шрифты из @fontsource в public/fonts
npm run dev          # http://localhost:4321/our-games/
```

Сборка и локальный просмотр готового сайта:

```bash
npm run build
npm run preview
```

Поиск (Pagefind) индексируется только во время `npm run build`, поэтому
в режиме `dev` он появляется лишь после хотя бы одной сборки.

## Как добавить игру

1. Создайте `src/content/games/<slug>/index.md`. Slug — латиницей, как в
   адресе: `vangers`, `stalker-shoc`, `atomic-heart`.
2. Заполните frontmatter по образцу любой существующей игры. Обязательные
   поля: `name`, `type`, `class`, `developer`, `country`, `years.start`,
   `platforms`, `summary`. Поле `status: article` означает готовую статью,
   `card` — карточку реестра с пометкой «коротко».
3. Связи указываются один раз, с любой стороны: если у «Аллодов 2» прописан
   `predecessors: [allods]`, то на странице «Аллодов» сам появится преемник.
4. Эпоха вычисляется по году выхода; переопределить можно полем `era`.
5. Ссылки на несуществующие записи **роняют сборку** со списком проблем —
   это защита от опечаток в идентификаторах.

Схемы всех коллекций описаны в [`src/content.config.ts`](src/content.config.ts),
правила для авторов — в [`docs/authoring.md`](docs/authoring.md).

## Медиа

### Скриншоты из Steam

```bash
npm run steam:fetch                    # все игры со steamAppId и без галереи
npm run steam:fetch -- stalker-shoc    # только эти игры
npm run steam:find                     # подобрать steamAppId по названию, с проверкой
npm run steam:fetch -- --refetch perimeter
```

Магазин Steam отдаёт карточку игры открытым JSON без ключа: оттуда берутся
скриншоты, широкая обложка библиотеки и имена разработчика с издателем — они
идут в подпись как правообладатели. Часть игр снята с продажи в российском
регионе, поэтому скрипт переспрашивает карточку в американском.

Идентификатор приложения **нельзя выдумывать**: число само по себе ведёт на
какую-нибудь карточку, и кадры приедут от чужой игры. Так у «Корсаров III»
однажды оказались скриншоты «Периметра 2», у Ex Machina — японского шутера
Crimzon Clover, а у «Вдали» — набора машин для Forza Horizon 4. Отсюда две
проверки:

```bash
npm run steam:check                # сверить подписи кадров с названием игры
npm run steam:check -- --purge     # убрать чужие кадры и неверный идентификатор
npm run steam:find                 # подобрать идентификатор по названию
npm run steam:find -- --write      # вписать подтверждённые совпадения
```

Сверка работает по подписи, которую оставляет `steam:fetch`: в ней хранится
настоящее имя карточки, и расхождение с названием игры видно сразу.

Подбор принимает находку, только когда имя карточки в точности совпадает с
нашим — с точностью до «&» против «and», приписок вроде HD, Gold и Anthology
и знаков препинания. Вхождения недостаточно: иначе «Sudden Strike 5» сойдёт
за «Sudden Strike», «Perestroika Drive» за «Перестройку», а «DOA6LR Character
Unlock Key» — за Lada Racing Club, у которой сокращение LRC. Остальное
печатается списком и выбирается глазами: у «Чёрного ворона» и «ГЭГ» точные
тёзки в Steam оказались совсем другими играми.

### Изображения из Википедии

```bash
npm run wiki:fetch -- --game gag --title "ГЭГ: Отвязное приключение"
npm run wiki:fetch -- --game chasm --title "Chasm: The Rift" --lang en
npm run wiki:fetch -- --auto --dry     # посмотреть, что нашлось для игр без картинок
npm run wiki:check                     # картинка стоит в статье про свою игру?
```

Для игр, которых нет в Steam (а это вся советская эпоха и половина
девяностых), скриншоты и обложки берутся со страниц Википедии. Логотипы,
флаги и значки самой Википедии отсеиваются по имени файла.

Промах здесь тише, чем неверный номер в Steam: статья находится, картинка
скачивается, подпись собирается из нашего названия — и всё выглядит
правильно. Так у Ex Machina постером оказалась обложка британской «Deus Ex
Machina» 1984 года, у «Проклятых земель» — обложка сиквела, а у DCS: Black
Shark — коробка DCS World. По имени файла это не поймать: половина картинок
лежит под транслитерацией (`Mehanoid_26581`) или аббревиатурой (`ШХЗСС`).
Зато Википедия знает, в каких статьях файл стоит, и `wiki:check` спрашивает
именно это. Расхождение чинится одним из двух способов: если картинка своя,
а название у неё западное или старое — оно дописывается в `altNames` игры;
если чужая — удаляется.

### Снимки мобильных игр из App Store

```bash
npm run appstore:fetch -- fishdom homescapes township
npm run appstore:fetch -- fishdom --dry        # посмотреть, что нашлось
npm run appstore:fetch -- --id 664575829 fishdom
```

Мобильных игр нет ни в Steam, ни на Викискладе, а в Википедии статьи о них
без картинок — Fishdom, Homescapes и Township так и стояли с пустыми
карточками. Зато Apple отдаёт карточку приложения открытым JSON без ключа, и
в ней лежат и снимки экрана, и настоящее имя издателя.

Основание то же, что у кадров из Steam: это промо-материалы, которые издатель
сам выложил в витрину магазина. Идентификатор приложения, как и в Steam,
не выдумывается: скрипт ищет по названию сам и принимает находку только при
строгом совпадении имён — с поправкой на магазинные хвосты вроде
«Homescapes: Match 3 Games».

### Фотографии техники с Викисклада

```bash
npm run commons:fetch -- --search "Dendy Junior"              # найти файлы
npm run commons:fetch -- --files "File:Dendy Junior.jpg" --platform dendy
npm run commons:fetch -- --category "PlayStation Vita" --era tens --limit 3
npm run photos:shrink                                          # ужать исходники
```

Принимаются только CC0, CC BY, CC BY-SA и общественное достояние; лицензия и
автор сохраняются рядом с файлом и печатаются на `/licenses/`. Имена файлов
в `--files` разделяются вертикальной чертой: в названиях с Викисклада
попадаются запятые.

### Видео

```bash
npm run video -- --query "Вангеры обзор" --limit 10      # посмотреть, что есть
npm run video -- --auto all --take 2 --report tmp/video/all   # найти и записать отчёт
npm run video -- --repick tmp/video/all.jsonl --take 2        # пересудить отчёт новыми правилами
npm run video -- --sheet tmp/video/all-2.jsonl                # лист с превью для просмотра
npm run video -- --apply tmp/video/all-2.jsonl --skip tmp/video/no.txt
npm run video -- --game vangers --add <ссылка>                # вписать конкретный
npm run video -- --game vangers --drop <id>                   # убрать
```

Идентификаторы роликов не выдумываются: они берутся из выдачи площадок,
оттуда же приходят настоящее название, канал и превью. YouTube и Rutube
отвечают без ключа; VK Видео закрыт целиком и требует `VK_TOKEN` в `.env`.

Отбор строгий, иначе половина выдачи окажется чужой. В названии должна
стоять сама игра, длительность — от полутора минут до четырёх часов, а в
названии не должно быть мусорных примет: реакции, нарезки, «топ-10»,
ролики про читы и скачивание.

Главная беда — **каналы-фермы на Rutube**. Они заливают чужие игровые ролики
под именами вроде «Секреты ухода за кожей», «Рецепты вегетарианских закусок»
или «Женская психология и саморазвитие»: само видео настоящее, но автор у него
другой, а подписать его чужим именем хуже, чем не ставить вовсе. Отсюда три
сита по имени канала: чужая тема, шаблонное имя («Игровые Загадки», «Геймеры
и Магия», «Обзоры игр: стоит ли играть?») и слишком длинное имя. Плюс
проверка на повтор: один и тот же ролик часто лежит и на YouTube, и
перезалитым на Rutube, и без неё статья получала его дважды.

Вторая беда — **названия из обычных слов**. «Сафари», «Снайпер», «Клад»,
«Вдали», «Вектор» — это не имена собственные, а обиходные слова, и поиск на
них приносит обзор браузера Safari, китайский боевик, разбор айсберга в GTA
и обзор скутера Vector. Слова «обзор» в заголовке тут мало: им подписывают
что угодно. Поэтому названию без единой цифры требуется примета самой
игры — геймплей, прохождение, летсплей, история серии.

Для таких игр всё равно вернее искать запросом по существу. Советскому
автомату нужен запрос «игровой автомат Морской бой», карманной игре —
«Электроника Тайны океана»; найденное вписывается ключом `--add`.

Большой проход удобнее делать в два шага — запросы к площадкам занимают
около часа, и повторять их ради правки отбора незачем: `--repick`
пересобирает отбор по готовому отчёту, не трогая площадки. В отчёт кладутся
не только взятые ролики, но и запас — восемь следующих по рейтингу.

Последнее слово всё равно за человеком: `--sheet` делает страницу с превью,
кнопка «Мимо» собирает внизу список отклонённых, и он передаётся ключом
`--skip` к `--apply` (или `--purge`, если ролики уже вписаны).

## Как устроен код

| Путь | Назначение |
| --- | --- |
| `src/content.config.ts` | схемы коллекций: игры, студии, серии, движки, платформы, эпохи |
| `src/lib/graph.ts` | граф связей, встречные ссылки, проверка целостности |
| `src/lib/relations.ts` | четыре вида родства между играми |
| `src/lib/layout.ts` | укладка полос для карты связей |
| `src/lib/paths.ts` | адреса с учётом подпути сайта |
| `src/components/` | компоненты страниц |
| `src/styles/` | сброс, общие элементы, токены оформления |
| `src/scripts/` | клиентские скрипты: прочитанное, навигация, фильтры, карта |
| `public/themes/` | пять тем эпох плюс нейтральная тема служебных страниц |
| `scripts/` | инструменты: шрифты, Steam, Википедия, Викисклад, видео, проверки |
| `scripts/seed/` | реестр заготовок, с которого начинался контент |

## Проверки

```bash
npm run content:validate     # схема, обязательные поля, авторы у изображений
npm run links:check          # относительные ссылки внутри статей
npm run steam:check          # кадры из Steam принадлежат своим играм
npm run wiki:check           # картинки из Википедии — тоже (нужна сеть)
npm run contrast:check       # контраст текста во всех темах, светлой и тёмной
npm run coverage             # полнота: где статьи, скриншоты и видео, а где пробелы
npm run check                # типы (astro check)
npm run build                # ссылки между записями: висячая роняет сборку
```

## Публикация

Сайт живёт на GitHub Pages в подпапке `/our-games/`. Сборку делает
GitHub Actions при каждом пуше в `main` (см.
[`.github/workflows/deploy.yml`](.github/workflows/deploy.yml)).

Подпуть и адрес читает `astro.config.mjs` из переменных `SITE_BASE` и
`SITE_URL`; без них берутся значения для Pages. **Задавать их в Git Bash
нельзя**: MSYS подменяет одиночный `/` на `C:/Program Files/Git/`.
Из PowerShell:

```powershell
$env:SITE_URL='https://example.com'; $env:SITE_BASE='/'; npm run build
```

## Права на изображения

Скриншоты, обложки и промо-арт принадлежат разработчикам и издателям игр и
приводятся в информационных целях — как иллюстрация к статье о самой игре, в
ограниченном числе и уменьшенном размере, так же, как это делают Википедия,
MobyGames и игровая пресса. Правообладатель указан у каждого изображения, а
полный список — на странице `/licenses/`.

Фотографии приставок и компьютеров взяты с Викисклада на условиях свободных
лицензий, с именем автора и ссылкой на файл. Видеоролики не размещаются на
сайте: они проигрываются с YouTube и Rutube после нажатия, права на них
принадлежат авторам каналов.

Тексты статей написаны для этого проекта.
